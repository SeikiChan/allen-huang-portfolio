# Portfolio design explorations

## Questionnaire-based direction — October 17, 2026

- `allen.html`, `allen.css`, `allen.js`: independent, reviewable homepage prototype, not yet adopted as the main homepage.
- Personal positioning: AI product exploration/prototyping and game/interactive creativity/team leadership. Present goal framing, hands-on experiments, explicit judgment, and responsibility through project evidence.
- User explicitly excludes orange to avoid perceived affiliation with Claude. Palette: warm off-white, forest ink, cobalt accents; slate blue / moss / pale violet for individual projects. Use an arrow beside Allen's wordmark.
- The user's computer/many-tabs metaphor is private: do not use it in public copy or visual identity.
- Layout: large Chinese headline, interactive three-step thinking diagram, asymmetric project chooser, expandable decision rationale, personal approach, contact.
- Project art is labeled conceptual illustration, not screenshots or live results. Existing case-study pages remain the linked destinations.
- Optional Google Fonts enhance typography; local sans-serif and serif fallbacks are included. Respect reduced motion and use native buttons/disclosures.

These are four selectable homepage concepts, not an approved replacement for the main site.

- A / poster: large sans-serif headlines, red and warm white, a compact horizontal project index. Communicates decisive product thinking.
- B / gallery: serif typography, white space, a sculptural hero and staggered project exhibits. Gives different project themes room within a consistent frame.
- C / lab: charcoal and lime, a human-intent diagram, and an accessible button-driven project browser. Communicates systems thinking; selected project is controlled by aria-pressed and hidden panels.
- D / studio: paper tones, yellow notes, layered illustration and expandable project notes. Communicates curiosity and collaborative making.

All concepts share the same factual project scope. Illustrations are conceptual, not product screenshots or performance data. Existing case-study links are relative. No external fonts, frameworks or assets are required.

Open index.html through the local web server to compare live desktop previews. Each concept has a top navigation switcher. The preview query hides that switcher inside overview thumbnails. Responsive rules stack the layouts on narrow screens; decorative marks yield space to readable content.
